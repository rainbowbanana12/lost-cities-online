# Lost Cities Online v5.4

기존 Hybrid v5.3 Mobile UI와 게임 규칙을 그대로 유지하면서 인터넷 서버 배포가 가능하도록 연결 구조를 바꾼 버전입니다.

## 온라인에서 달라진 점
- 서로 다른 Wi-Fi, LTE/5G, PC/휴대폰 사이에서도 동일한 공개 주소로 접속 가능
- 방 코드는 기존과 동일한 4자리 방식
- 방을 만든 뒤 주소에 `?room=ABCD`가 붙어 상대에게 URL째 공유 가능
- 새로고침 또는 잠깐의 네트워크 끊김 뒤 자동 재접속
- 브라우저의 localStorage에 방 코드와 개인 재접속 토큰 저장
- 연결이 끊겨도 5분 동안 방을 유지
- 6시간 동안 활동이 없는 방은 자동 삭제
- `/healthz` 상태 확인 엔드포인트 추가
- Dockerfile / Procfile 포함

## 로컬 테스트
Node.js 20 이상:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000`

## 인터넷 배포
Node.js 웹 서버 또는 Docker 컨테이너를 실행할 수 있는 서비스에 이 폴더 전체를 배포합니다.

필수 조건:
- 실행 명령: `npm start`
- 서비스가 지정하는 `PORT` 환경변수를 그대로 사용
- WebSocket/Socket.IO 연결 허용
- HTTPS 사용 권장
- 인스턴스는 1개로 운영

배포가 끝나면 두 플레이어 모두 같은 공개 HTTPS 주소로 접속하면 됩니다.

예:
`https://your-game.example`

한 명이 방을 만들면 URL이:
`https://your-game.example/?room=ABCD`
형태가 되므로 이 주소를 상대에게 보내면 방 코드가 자동 입력됩니다.

## 현재 프로토타입의 서버 저장 방식
방과 게임 상태는 서버 메모리에 저장됩니다. 따라서 서버 프로세스가 재시작되거나 배포가 다시 이루어지면 진행 중인 방은 사라집니다.

여러 서버 인스턴스를 동시에 띄우거나 재배포 후에도 방을 보존하려면 Redis/DB 기반 저장소와 Socket.IO 어댑터를 추가해야 합니다. 현재 버전은 친구끼리 온라인으로 플레이하는 단일 서버 프로토타입에 맞춰져 있습니다.
